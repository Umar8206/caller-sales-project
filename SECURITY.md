# Security Policy

## Supported versions

Only the latest version on `main` receives security fixes.

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report security issues via [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on this repo, or email `uar8206@gmail.com` directly.

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix if you have one

You can expect an acknowledgement within 48 hours and a status update within 7 days.

## Credentials and secrets

If you find exposed credentials in this repo (or its git history), please report them immediately so they can be rotated. Do not use them.

Third-party services (ElevenLabs, Twilio) have their own security practices and responsible disclosure programs.
